# Blank Project

A clean starting point for a new website. The prior Meal Mate interface, app routes, backend functions, and assets have been removed.

## Development

```bash
npm install
npm run dev
```

The site intentionally renders a completely blank white page. It uses the existing React, TanStack Start, Vite, and Lovable integration. The generated route tree is regenerated by the router plugin on development/build.

No old backend services are invoked. Reconnect services explicitly when the next project needs them.
